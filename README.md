# HabitFlow

A responsive, client-side habit tracking dashboard designed as a portfolio showcase project.

## Features

- Create, edit, delete, search, and complete daily habits
- Persistent browser storage using `localStorage`
- Dashboard with daily progress, weekly activity, and a monthly goal
- Habit management table, analytics dashboard, calendar activity view, and settings
- Reminder controls and responsive mobile layout

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static web server.

## Deployment

This project contains no build step and can be deployed directly to Vercel as a static site.
